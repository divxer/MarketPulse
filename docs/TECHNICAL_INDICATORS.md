## 第一课:均线(MA / SMA / EMA)

### 核心概念:为什么需要均线?

K 线本身代表每天的 OHLC,但**单日波动有大量噪声**——AAPL 可以今天涨 3% 明天跌 2%,人眼看趋势很难。

**均线 = 给收盘价做平滑**。波动是浪,均线是潮。

形象比喻:浪给你今天的心情;潮告诉你两个月趋势走哪边。

### SMA(简单移动平均)

最直观——**最近 N 天收盘价的算术平均**:

```
SMA20(今天) = (close[-20] + close[-19] + ... + close[-1]) / 20
```

明天的 SMA20:扔掉 21 天前那个,加入今天的。"窗口在滑动"。

**SMA 的特点:对所有 N 天权重一样**。20 天前那一天和昨天的权重都是 1/20。

### EMA(指数移动平均)

**问题:** 直觉上,昨天的价格比 20 天前更重要。SMA 对此没区别对待。

**EMA 给近期数据更高权重**,权重按指数衰减:

```
EMA(今天) = α × close(今天) + (1 - α) × EMA(昨天)
其中 α = 2 / (N + 1)
EMA12 时 α ≈ 0.154,EMA26 时 α ≈ 0.074
```

**直觉差异:**
- 同样的周期,**EMA 比 SMA 反应快**(因为最近数据权重高)
- 价格突变后,EMA 更快"跟上",SMA 滞后更久
- 代价:EMA 更敏感 = 更容易给假信号

**用途不同:**
- 短线/趋势跟踪 → **EMA**(快)
- 长期支撑/阻力位 → **SMA**(稳)
- MACD 内部用 EMA(12, 26)是因为它要捕捉动量,需要敏感

### 周期的含义(20 / 50 / 200)

| 周期 | 大致意义 | 谁在看 |
|---|---|---|
| **20 天** | 近一个月情绪 / 短期 | 短线交易者 |
| **50 天** | 近两个半月动量 / 中期 | 摆动交易者 |
| **200 天** | 近一年趋势 / 牛熊分水岭 | 长线投资人 / 机构 |

**经验法则:**
- **股价 > SMA200 → 长期牛市;股价 < SMA200 → 长期熊市**(机构常用的简单滤波)
- SMA20 在 SMA50 之上 → 短期强于中期,动量向上
- SMA50 在 SMA200 之上 → 中期强于长期,趋势仍多头
- 反之类推

### MarketPulse chart 上的 4 条均线

| 线 | 颜色 | 代表 |
|---|---|---|
| EMA12 | 浅蓝 | 短期动量(MACD 的组件之一) |
| EMA26 | 橙色 | 中期动量(MACD 另一组件) |
| SMA50 | 紫色 | 中期趋势 |
| SMA200 | 灰色 | 长期趋势(牛熊分水岭) |

### 实战例子:AAPL 2026-05-12

```
Close:   $294.80
EMA12:   $283.58   (-3.8% vs close)
EMA26:   $275.30   (-6.6% vs close)
SMA50:   $263.74  (-10.5% vs close)
SMA200:  $257.32  (-12.7% vs close)
```

**注意排列顺序:** `Close > EMA12 > EMA26 > SMA50 > SMA200` — 经典完美多头排列。

直觉理解每一行差值告诉你什么:

1. **Close > EMA12 by 3.8%** → 短期均价仍在追赶价格,说明**近期有动量**
2. **EMA12 > EMA26 by 3.0%** → 近 12 天均价高于近 26 天均价,**短期强于中期**
3. **EMA26 > SMA50 by 4.4%** → 中期动量超过中期趋势
4. **SMA50 > SMA200 by 2.5%** → 中期趋势强于长期趋势 = **黄金交叉状态**
5. **Close 比 SMA200 高 12.7%** → 远高于年线,**机构视角的长期牛市**

**反面参照(假想):** 如果是 `Close < EMA12 < EMA26 < SMA50 < SMA200`,完全相反 = 完美空头排列 = 各时间维度都下跌 = 死亡螺旋。

真实场景大多介于两个极端之间:
- 价格刚突破 SMA50 但 SMA50 还在 SMA200 之下 → 反弹但未确认趋势反转
- EMA12 跌破 EMA26 但 SMA50 还在 SMA200 之上 → 长期牛市中的短期回调

### 第一课要点

- 均线是**潮**,K 线是**浪**
- SMA 平稳,EMA 敏感
- 周期越长越代表长期趋势
- **均线相对位置告诉你时间维度间的强弱关系**——这比"上涨还是下跌"更有信息量

## 第二课:MACD(Moving Average Convergence Divergence)

### 它解决什么问题

第一课我们看了 EMA12 和 EMA26 的相对位置。但**看两条线交错画在一起,人眼很难精确读出"差多少、变化多快"**。

MACD 的本质就是:**把 EMA12 和 EMA26 之间的距离,单独画一张图**。这样动量信息就**孤立可见了**。

### 三个组件

| 组件 | 国内常叫 | 算法 | 物理意义 |
|---|---|---|---|
| **MACD line** | DIF | `EMA12 - EMA26` | 短期 vs 中期的"差值" |
| **Signal line** | DEA | `EMA9(DIF)` | DIF 自己的 9 天 EMA(再平滑一层) |
| **Histogram** | 红/绿柱 | `DIF - DEA` | 两条线之间的距离 |

### 实战例子:QUBT 2026-05-12

```
EMA12 = 9.84    EMA26 = 9.18
DIF = EMA12 - EMA26 = 0.652

DIF 5 天前 = 0.413
DIF 今天   = 0.652
→ DIF 在 5 天里从 0.413 涨到 0.652,**正在走宽**
  = EMA12 远离 EMA26 = 短期均线甩开中期 = 动量加速

DEA(DIF 的 9 天 EMA) = 0.487
Histogram = DIF - DEA = 0.652 - 0.487 = 0.165
```

### 怎么读这三个组件

#### 1. DIF 在 0 的哪一边?

- **DIF > 0** → EMA12 > EMA26 → **短期强于中期**(bull)
- **DIF < 0** → 短期弱于中期(bear)
- **DIF = 0 附近** → 两条均线在交叉,**趋势转折点常出现在这**

#### 2. DIF 和 DEA 谁在上?

- **DIF > DEA** → MACD 的"金叉状态"——动量持续向上
- **DIF < DEA** → 死叉状态——动量减弱
- **DIF 上穿 DEA** = MACD 金叉(经典买入信号)
- **DIF 下穿 DEA** = MACD 死叉(经典卖出信号)

#### 3. Histogram(柱状)告诉你"加速度"

这是 MACD 中最微妙也最有信息量的部分:

- Histogram **绿色变高** → DIF 在远离 DEA → 动量在加速向上(**最早期的看涨信号**)
- Histogram **绿色变矮** → DIF 在向 DEA 靠近 → 动量在减弱(虽然还在涨,但**减速了**)
- Histogram **变红又变低** → 加速下跌
- Histogram **变红但变浅** → 跌势在减缓

### 三个信号的早晚顺序

按"出现时间从早到晚"排:

1. **Histogram 转向**(最早、最敏感、假信号最多)—— "二阶导"换号
2. **MACD 金叉/死叉(DIF 穿 DEA)**(中等)—— "一阶导"换号
3. **DIF 穿过 0 线**(最晚,但最确认)—— "零阶"换号

**实战权衡:**
- 想抓早 → 看 Histogram(代价:假信号)
- 想抓稳 → 等 MACD 金叉(代价:慢)
- 想抓最确认 → 等 DIF 穿 0(代价:最慢,常常已经涨/跌一大段了)

### 常见误解

| 误解 | 真相 |
|---|---|
| "MACD 金叉一定涨" | 错。震荡市里 MACD 反复金叉死叉,每次都骗你。**只在趋势市有效** |
| "DIF 越高越好" | 错。DIF 越大,意味着 EMA12 已经偏离 EMA26 很远 = 短期已经涨了一截 = **可能近期回调** |
| "Histogram 高=买入" | 错。Histogram 高 = 加速向上中,但**它会先减速才反转**。"高位 Histogram 见顶"反而常出现 |
| "MACD 数值跨股票可比" | 错。**MACD 数值是绝对值**——AAPL 的 DIF 是几块钱,QUBT 的 DIF 是 0.6,**不能直接比较** |

### 实用心法

- **金叉 + DIF > 0** = 更可靠的买点(短期反转 + 已在多头区域)
- **死叉 + DIF < 0** = 更可靠的卖点
- **金叉 + DIF < 0** = "底部反弹"信号,但还没确认趋势反转
- **死叉 + DIF > 0** = "高位震荡",可能只是调整

### 第二课要点

- MACD 就是把 EMA12 - EMA26 单独画
- DIF / DEA / Histogram 各代表"差值 / 平滑后的差值 / 二者距离"
- 信号灵敏度:Histogram > 金叉/死叉 > DIF 穿 0
- MACD 数值是绝对的,跨股票不可比

## 第三课:RSI(Relative Strength Index)

### 它在测什么

RSI 测的是**最近的上涨力量 vs 最近的下跌力量的比例**。

注意:**"Strength" 不是"相对于另一只股票"**,这个名字误导了无数人——它衡量的是同一只股票自己的**涨跌压力对比**。

公式(看一眼就行,不用记):

```
对最近 14 天:
  avg_gain = 上涨日涨幅的平均(下跌日记 0)
  avg_loss = 下跌日跌幅的平均(上涨日记 0)
  RS = avg_gain / avg_loss
  RSI = 100 - 100 / (1 + RS)

特例:
  连续 14 天全涨 → avg_loss = 0 → RSI = 100
  连续 14 天全跌 → avg_gain = 0 → RSI = 0
  涨跌等量 → RSI = 50
```

**直觉:** RSI 是"最近 14 天里,涨 vs 跌占多少比例"的归一化分数。

### 实战例子:QUBT 2026-05-12

```
RSI today:        71.08   ← 处于超买区(>70)
RSI 5 days ago:   61.08
RSI 20 days ago:  60.26
最近 20 个 bar:    10 涨 / 10 跌
```

5 天前到今天:RSI 从 61 → 71,**上行 10 个点,加速进入超买**。

注意一个有意思的细节:**最近 20 天涨跌各 10 天**,涨跌天数差不多。但 RSI 却很高(71)——为什么?

**因为 RSI 看的不是涨跌天数,而是涨跌"幅度"。** 最近 14 天里,**涨日的平均涨幅明显大于跌日的平均跌幅**——所以 avg_gain / avg_loss 比值高,RSI 拉到 71。

这是 RSI 的核心特征:**它是"幅度加权"的,不是"次数计数"的**。

### 三个区域

```
0 ───── 30 ───────────── 50 ───────────── 70 ───── 100
        超卖              中性              超买
       (oversold)                       (overbought)
```

- **RSI > 70** 超买区:最近涨势占主导,涨幅明显大于跌幅
- **RSI < 30** 超卖区:最近跌势占主导,跌幅明显大于涨幅
- **30-70 中性区**:无明显单边压力

**注意:** 超买 ≠ 卖出信号,超卖 ≠ 买入信号。这是 RSI 最大的误解。

### 最大误解:超买不等于"该卖"

**错误理解:** RSI > 70 = 涨太多 = 该卖了。

**真相:** 强趋势中,RSI 可以**在超买区停留几周甚至几个月**。

举例:2020-2021 AAPL 长牛市,RSI 长期在 70+ 浮动。如果你 RSI=70 就卖,会**错过整段大涨**。

**经验法则:**
- **震荡市**:RSI 70 卖、30 买 → 有效(均值回归)
- **强趋势市**:RSI 70 卖 = 太早,RSI 30 买 = 接刀
- **判断标准**:配合趋势指标(SMA200 / MACD 等)看是震荡还是趋势

### RSI 真正最有用的:**背离(Divergence)**

这是 RSI 最值钱的信号,远比"超买超卖"重要。

#### 顶背离(看跌信号)

```
价格:    新高 ↑
RSI:     更低 ↓        ← 价格创新高但 RSI 没创新高
```

意义:**价格上涨,但"涨的力量"在变弱**——上方接盘不积极,可能见顶。

#### 底背离(看涨信号)

```
价格:    新低 ↓
RSI:     更高 ↑        ← 价格创新低但 RSI 没创新低
```

意义:**价格下跌,但"跌的力量"在变弱**——卖盘竭尽,可能见底。

**为什么背离有效:** 价格是"结果",RSI 是"力量"。当结果和力量分歧时,力量先衰竭的一方先反转。

**背离的局限:** 信号常常**早**——价格可以继续创新高/新低好几次后才反转。背离是预警,不是入场。

### 常见误用清单

| 误解 | 真相 |
|---|---|
| "RSI 70 一定回调" | 错。强趋势可以在 70-90 区间挂半年 |
| "RSI 30 一定反弹" | 错。下跌趋势可以挂在 20-30 很久 |
| "看 RSI 数值大小判断买卖" | 错。**看 RSI 的趋势 + 价格的趋势是否一致**(背离)才有信号 |
| "RSI 50 是中性点" | 半对。50 是数学中点,但实际可以把 50 看作"上下方向分水岭" |
| "周期越短越精准" | 错。RSI 周期越短越敏感(假信号也越多)。RSI(14) 是 Wilder 原始设定 |

### 不同周期的 RSI

- **RSI(6)** 极短期,日内交易,噪声大
- **RSI(14)** **标准**,MarketPulse chart 用的就是 14
- **RSI(21)** 中期,更平稳
- **RSI(30/50)** 长期,几乎只剩"长期是否过热"信号

### 第三课要点

- RSI 测"涨跌力量比例",不是相对其它股票
- 0-100 区间,70/30 是经验阈值
- **超买 ≠ 卖出**,要看趋势状态
- **背离才是 RSI 最值钱的信号**
- 单独看 RSI 数值意义不大,要和趋势指标结合

## 第四课:布林带(Bollinger Bands)

### 它的本质:**统计学包络线**

EMA、MACD、RSI 都基于"近期 vs 远期"的对比。布林带不一样——它基于**统计分布**:

**核心思想:** 如果 SMA20 是"近 20 天的均值",那 ±2 个标准差 σ 大概率包住未来的价格。

```
中轨   = SMA20(20 日简单均线)
上轨   = SMA20 + 2σ      ← σ 是 20 天收盘价的标准差
下轨   = SMA20 - 2σ
```

**数学直觉:** 如果价格服从正态分布,**~95% 的点落在 ±2σ 之内**。所以理论上价格应该 95% 时间在上下轨之间。

**注意:** 股价不是正态分布(尾部更胖,极端事件更多)——这是 BB 的固有局限。

### 实战例子:QUBT 2026-05-12

```
Close:      $11.03
SMA20:      $9.60   (中轨,20 日均价)
σ:          0.786   (20 日收盘价标准差)

BB Upper = 9.60 + 2 × 0.786 = $11.17
BB Lower = 9.60 - 2 × 0.786 = $8.03

Bandwidth today:  32.74%
Bandwidth 20d ago: 35.34%
%B today:         95.5%   ← 价格距下轨 95.5%,几乎贴上轨
```

### 三个关键观察

#### 观察 1:**Bandwidth(带宽)= 波动率**

带宽公式:`(上轨 - 下轨) / 中轨 × 100%`

- 带宽**变宽** = 波动加大(股价摆得猛)
- 带宽**变窄** = 波动收敛(股价摆得窄,蓄势)

QUBT 带宽 32.7% 对一个 $10 股来说**很高**——意味着这股**剧烈波动中**。AAPL 平时带宽可能 5-10%。

#### 观察 2:**%B = 价格在通道里的位置**

`%B = (price - lower) / (upper - lower)`

- %B = 100% → 贴上轨
- %B = 50% → 正中(SMA20 上)
- %B = 0% → 贴下轨
- %B > 100% → **价格冲破上轨**(强势)
- %B < 0% → 价格跌破下轨(弱势)

### 最大误解:碰上轨不等于"卖出"

**错误理解:** 价格碰上轨 = 偏离均值 2σ = 该回归 = 卖。

**真相:** 强趋势中,价格会**沿着上轨"散步"几周**——这叫 **Walking the Band**。

观察方法:
- **沿着上轨走** = 强趋势(每天收盘都在 %B 80-100% 区间)
- **从上轨快速回落到中轨** = 第一个回调信号
- **碰下轨反弹** = 在震荡市有效;在熊市继续创低很常见

### BB 真正最值钱的信号:**Squeeze(挤压)**

带宽收窄到历史低位 → 股价波动极小 → "弹簧被压紧" → **大概率即将爆发大行情**(方向未定)

```
波动率周期(由 Bandwidth 看):
  低波动(squeeze) → 高波动(expansion) → 低波动 → ...
```

这是经验法则:**低波动率均值回归**。当 BB 挤压到极致,下一步几乎必然是放大波动——可能向上突破上轨,也可能向下击穿下轨。

**操作:** Squeeze 期间**等突破方向确认再入场**,不要 squeeze 中就猜方向。

### 三种典型形态

#### 形态 1:**Band Walk(沿带散步)**

强趋势,不要逆势卖。AAPL 2020-2021 大牛市,沿着 BB 上轨走了大半年。

#### 形态 2:**Squeeze + Breakout(挤压突破)**

带宽急剧扩大,价格强势单边。

#### 形态 3:**Bounce in Range(震荡市的均值回归)**

价格在上下轨间反复。

**碰上轨可卖,碰下轨可买**——只在这种状态有效。

**怎么判断是震荡市?** SMA20 大致水平、SMA50 也大致水平、带宽稳定 → 震荡市。

### 常见误用清单

| 误解 | 真相 |
|---|---|
| "碰上轨 = 卖" | 错。看是 walking the band 还是 mean reversion |
| "Squeeze 之后必然大涨" | 错。Squeeze 必然爆发,但方向**未定**——可能大跌 |
| "带宽越宽风险越大" | 半对。带宽宽=已经波动了,可能即将均值回归;但单看带宽不够 |
| "BB 不用 2σ 用 1σ 信号更多" | 错。1σ 包住 ~68% 数据,假信号爆炸。Wilder 选 2σ 是经验值 |
| "BB 适合所有股票" | 错。低波动股(KO、JNJ)上 BB 几乎不变,**信号稀疏**。BB 在中-高波动股上更有用 |

### 第四课要点

- BB = SMA20 ± 2σ,**统计学包络**
- 带宽变化代表波动率变化
- %B 告诉你价格在通道里的位置
- **Walk the Band ≠ 该卖**——看趋势状态
- **Squeeze 是 BB 最值钱的形态**——预示大行情(方向未定)
- 单独看 BB 不够,要和 RSI/MACD/趋势状态结合

## 第五课:K 线上的信号 Marker(综合实战)

### MarketPulse chart 上的 6 种 marker

每种都是前 4 课某个指标"穿过阈值"的瞬间被标记出来:

| Marker | 含义 | 触发条件 | 来源指标 |
|---|---|---|---|
| 🟢 **金叉** (`ema_golden_cross`) | 短期均线上穿中期均线 | EMA12 从 ≤ EMA26 变为 > EMA26 | 第一课 EMA |
| 🔴 **死叉** (`ema_death_cross`) | 短期均线下穿中期均线 | EMA12 从 ≥ EMA26 变为 < EMA26 | 第一课 EMA |
| ⚠️ **超买** (`rsi_overbought`) | RSI 进入超买区 | RSI(14) 第一次 ≥ 70 | 第三课 RSI |
| ⚠️ **超卖** (`rsi_oversold`) | RSI 进入超卖区 | RSI(14) 第一次 ≤ 30 | 第三课 RSI |
| 📈 **上轨** (`bollinger_upper`) | 收盘价突破 BB 上轨 | close > SMA20 + 2σ | 第四课 BB |
| 📉 **下轨** (`bollinger_lower`) | 收盘价跌破 BB 下轨 | close < SMA20 - 2σ | 第四课 BB |

### 去重机制(重要!)

代码用了 **first-fire dedup**:一个信号一旦触发,直到它**停止触发**才能再标一次。

举例:
- RSI 连续 10 天都在 ≥70 → 只在**第一天**标一个"超买" marker,后 9 天不标
- 第 11 天 RSI 跌到 65(不再超买)→ 内部"重置"
- 第 12 天 RSI 又回到 72 → 再标一个"超买"

**意义:** chart 上看到的"超买"标记是"**进入超买区的时刻**",不是"超买持续中"。这点很多用户搞错。

### 6 个 marker 的可靠度排名(经验值)

| 排名 | Marker | 可靠度 | 备注 |
|---|---|---|---|
| 🥇 | **金叉/死叉** | ⭐⭐⭐⭐ | 趋势市最有效,震荡市常假信号 |
| 🥈 | **BB 上/下轨突破** | ⭐⭐⭐ | 趋势启动信号 OR 极值反转,二选一 |
| 🥉 | **RSI 超买/超卖** | ⭐⭐ | 单独看几乎没用,**只在背离时有效** |

**注意:** 以上是直觉值。MarketPulse 后续会加"信号胜率追踪"基础设施(见 `PRINCIPLES.md` #3),用真实数据替换直觉。

### 每种 marker 的实战陷阱

#### 🟢🔴 EMA 金叉 / 死叉

**最大陷阱:震荡市中的假信号**

- 震荡市:EMA12 和 EMA26 反复交叉 → 标记一堆金叉死叉,**每个都是假**
- 趋势市:金叉/死叉只发生 1-2 次,且**有效**

**如何过滤:**
- 看 SMA200。**金叉 + 价格在 SMA200 上方** = 多头中的二次确认 → 高可靠
- **金叉 + 价格在 SMA200 下方** = 熊市反弹,常常是假突破 → 低可靠

**滞后性:** EMA 是滞后指标,金叉时常常**已经涨了 5-10%**——别期待抄到底。

#### ⚠️ RSI 超买 / 超卖

**最大陷阱:在趋势市里反向操作**

- 强多头中 RSI 经常 70+ 几周 → 看到"超买"就卖会**踏空整段大涨**
- 强空头中 RSI 经常 30- 几周 → 看到"超卖"就买会**抄到刀**

**如何过滤:**
- **结合趋势方向**:超买在多头里是"动量加强";超卖在空头里是"动量加重"
- **只在震荡市里反向用**:横盘股,SMA20-50-200 缠绕在一起,超买卖、超卖买
- **背离才是真信号**(第三课重点):价格新高 RSI 没创新高 = 真顶部预警

**实战:** RSI marker 单独**很少作为入场依据**,作为风险提示更合适("注意,这里过热")。

#### 📈📉 Bollinger 上/下轨突破

**这是最暧昧的信号——两种完全相反的解读都对:**

**解读 A:Squeeze 后突破 = 趋势启动**
- 之前带宽很窄(squeeze),突然突破上轨 → **大概率持续上涨**(动量启动)
- 解读对应:**追涨**

**解读 B:震荡市的极端值 = 均值回归**
- 长期横盘,价格突然碰上轨 → **大概率回归 SMA20**
- 解读对应:**逆势卖**

**怎么知道是 A 还是 B?**
- 看突破**前**的 Bandwidth 状态:
  - 突破前 squeeze(带宽窄)→ A 解读(追涨)
  - 突破前 normal(带宽稳定)→ B 解读(均值回归)
- 看其它指标:
  - 突破上轨 + MACD 金叉 + RSI 还没超买 → A 解读
  - 突破上轨 + MACD 死叉 + RSI 已超买 → B 解读

### 多 marker **共振**(Confluence)= 最高可靠度

单 marker 假信号多。**多 marker 同时出现**(共振)信号大幅提升:

| 组合 | 含义 | 可靠度 |
|---|---|---|
| 🟢 金叉 + RSI 50-60 + 价格在 SMA200 上 | 趋势市启动 | ⭐⭐⭐⭐⭐ |
| 🟢 金叉 + 📈 上轨突破(squeeze 后)+ MACD 强势 | 完美启动信号 | ⭐⭐⭐⭐⭐ |
| 📉 下轨突破 + ⚠️ 超卖 + RSI 底背离 | 反转底部信号 | ⭐⭐⭐⭐ |
| 🔴 死叉 + ⚠️ 超买 + RSI 顶背离 | 反转顶部信号 | ⭐⭐⭐⭐ |
| 🟢 金叉 + ⚠️ 超买 + 📈 上轨突破 | **三重过热** ——别追 | ⭐⭐ 反向 |

### "怎么用 marker"的决策框架

看 marker 时按这个顺序问:

```
1. 当前是趋势市还是震荡市?
   ├─ 趋势市(均线明确分层,如多头排列)
   │  ├─ 金叉/死叉:有效,顺势操作
   │  ├─ 超买/超卖:不要逆势用,只作风险提示
   │  └─ BB 上下轨:walk the band 中,不是反转信号
   │
   └─ 震荡市(均线缠绕,SMA50 水平)
      ├─ 金叉/死叉:多数假信号,过滤掉
      ├─ 超买/超卖:可逆势用(均值回归)
      └─ BB 上下轨:可逆势用(回归 SMA20)

2. 此 marker 有没有其它 marker 共振?
   ├─ 有(至少 2 个同向)→ 可靠度 ×2
   └─ 没有 → 单一信号,谨慎

3. 此 marker 和价格、其它指标有没有背离?
   ├─ 有(顶/底背离)→ 反转信号,高可靠度
   └─ 无 → 趋势信号,中可靠度

4. 我的入场点和止损点能不能定义清楚?
   ├─ 不能 → 别交易,只是"观察"
   └─ 能 → 按计划执行
```

### 实战例子:QUBT 6 个月信号链回看

从 2025-10 到 2026-05 的真实信号:

```
2025-10-21  📉 BB 下轨  $16.00 (lower $16.29)    ← 下跌开始
2025-11-13  ⚠️ 超卖 + 📉 下轨  RSI 29.1, $10.03   ← 第一次探底
2025-12-04  📈 BB 上轨  $13.58                   ← 反弹
2026-01-15  🟢 金叉  $11.81 vs $11.79            ← 看似启动
2026-01-26  🔴 死叉  $11.69 vs $11.75            ← !! 11 天反转 = 假信号
2026-01-29  📉 BB 下轨  $10.18                   ← 继续跌
2026-02-05  ⚠️ 超卖 + 📉 下轨  RSI 29.6, $7.81    ← 第二次更深探底
2026-03-27  📉 BB 下轨  $6.66                    ← 最深点
2026-04-14  📈 BB 上轨  $8.11                    ← 反弹
2026-04-15  🟢 金叉 + ⚠️ 超买  $7.50, RSI 70.6   ← 强势反转(共振!)
2026-05-12  ⚠️ 超买 + 📈 BB 上轨  RSI 71.1, $11.78 ← 持续 walk the band
```

完整故事:QUBT 从 $16 → 跌到 $6.66(三个月跌 58%)→ 反弹到 $11.78(四个月涨 77%)。

**关键教学时刻:**

1. **2026-01-15 假金叉**:11 天后死叉。当时价格在下跌趋势中,金叉是熊市反弹 → 单看金叉不够,要看 SMA200 和趋势 context

2. **2026-02-05 + 03-27 底背离**:2/5 RSI 29.6 + BB 下轨;3/27 价格更低($6.66 vs $7.81)但**没出现 RSI 超卖 marker** → **底背离**!RSI 力量在变弱(虽然价格还在跌)

3. **2026-04-15 真金叉**:金叉 + RSI 超买 + BB 上轨突破 = **三重共振**。之后涨 57% → 共振信号在**底部反弹**时特别有效

4. **RSI 超买持续一个月**:4/15 标超买,5/12 再次标。中间被 dedup 机制吞了——说明 RSI 在 4/15 到 5/12 之间至少跌破过 70 然后又上去。**持续超买 = walk the band 状态**,别仅凭超买卖出

### 第五课要点

- 6 种 marker 都是前 4 课指标穿过阈值的瞬间
- **dedup 机制**:同一信号持续中只标一次(进入时刻)
- 单 marker 假信号多,**共振**才提升可靠度
- 看 marker 前先判断**趋势 vs 震荡**
- 背离比阈值穿越**信号更早更准**(但更难识别)

## 速查表

### 4 条均线含义

| 线 | 颜色 | 周期 | 用途 |
|---|---|---|---|
| EMA12 | 浅蓝 | 12 天 | 短期动量 |
| EMA26 | 橙色 | 26 天 | 中期动量 |
| SMA50 | 紫色 | 50 天 | 中期趋势 |
| SMA200 | 灰色 | 200 天 | 长期趋势(牛熊分水岭) |

### 排列形态

| 排列 | 含义 |
|---|---|
| Close > EMA12 > EMA26 > SMA50 > SMA200 | 完美多头 |
| Close < EMA12 < EMA26 < SMA50 < SMA200 | 完美空头 |
| 均线缠绕,SMA50 水平 | 震荡市 |
| 价格 > SMA200 | 长期牛市 |
| 价格 < SMA200 | 长期熊市 |

### MACD 信号

| 信号 | 含义 |
|---|---|
| DIF > 0 | 短期强于中期 |
| DIF > DEA | MACD 金叉状态 |
| DIF 上穿 DEA | MACD 金叉(买入信号) |
| DIF 下穿 DEA | MACD 死叉(卖出信号) |
| Histogram 转绿且增高 | 动量加速向上(最早) |
| Histogram 转红且增长 | 动量加速向下(最早) |

### RSI 阈值

| 区间 | 含义 |
|---|---|
| > 70 | 超买区 |
| < 30 | 超卖区 |
| 50 | 多空分水岭 |
| 顶背离 | 看跌反转预警 |
| 底背离 | 看涨反转预警 |

### Bollinger Bands

| 状态 | 含义 |
|---|---|
| 带宽变窄(squeeze) | 蓄势,大行情将至(方向未定) |
| 带宽变宽 | 波动率上升 |
| 沿上轨 walk | 强多头趋势,不要逆势 |
| 沿下轨 walk | 强空头趋势,不要逆势 |
| 震荡市中碰上轨 | 可卖(均值回归) |
| 震荡市中碰下轨 | 可买(均值回归) |

### 6 种 Marker 速记

| Marker | 触发 | 在...里有效 |
|---|---|---|
| 🟢 金叉 | EMA12 上穿 EMA26 | 趋势市 |
| 🔴 死叉 | EMA12 下穿 EMA26 | 趋势市 |
| ⚠️ 超买 | RSI ≥ 70 | 震荡市(反向)/ 趋势市(风险提示) |
| ⚠️ 超卖 | RSI ≤ 30 | 震荡市(反向)/ 趋势市(风险提示) |
| 📈 上轨 | close > SMA20 + 2σ | Squeeze 后启动 / 震荡市反向 |
| 📉 下轨 | close < SMA20 - 2σ | Squeeze 后启动 / 震荡市反向 |
